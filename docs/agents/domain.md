# Domain Docs

This is a single-context repository.

Before exploring or changing the codebase:

- Read the root `CONTEXT.md`.
- Read the ADRs under `docs/adr/` that apply to the work.
- Follow the project glossary and avoid synonyms it explicitly rejects.
- Surface any proposal that contradicts an existing ADR instead of silently overriding it.

If a referenced domain document does not exist, proceed silently. Create or revise domain documentation only when terminology or architectural decisions are actually resolved.
